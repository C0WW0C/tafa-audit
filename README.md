# Ibhextif — connaissance TAFA Elite

Cette arborescence constitue le registre local et versionné des connaissances de travail TAFA. Elle sert à retrouver les décisions, les sources, les stratégies et les backtests sans les présenter comme des instructions de trading réel.

Les registres sont conservés dans des fichiers YAML lisibles et peuvent ultérieurement être indexés dans une base relationnelle ou vectorielle. Toute mise à jour doit créer une nouvelle version de document, conserver la provenance et mettre à jour les relations correspondantes.

Consultez `SESSION_SCOPE.md` pour les limites de couverture, puis `sources.yaml`, `strategies.yaml`, `backtests.yaml` et `conversation_notes.yaml` pour les faits traçables.
