# Notes de release — TAFA X Elite M7 Paper/Demo OKX

Cette release complète le jalon M7 pour les tests contrôlés en paper/demo. Elle ajoute un launcher qui force le mode DEMO, une configuration d’environnement dédiée, une porte de release, une CI GitHub Actions, un test de non-régression du verrou paper/demo, un packager secret-free avec SHA-256 et un runbook de test.

Le périmètre de cette release est strictement limité au paper/demo avec données publiques OKX. Aucun ordre réel, aucune clé privée et aucune activation live ne sont requis pour le test prévu.
